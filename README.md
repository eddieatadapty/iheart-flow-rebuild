# iHeart Growth Audit

**Live → https://eddieatadapty.github.io/iheart-flow-rebuild/**

Five ideas to turn more iHeart users into subscribers, each built into a clickable version of iHeart's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask when radio can’t do it | +10–25% CR to purchase |
| 02 | Turn the first question into their presets | +10–20% CR to purchase |
| 03 | Make All Access the obvious pick | +5–15% ARPU |
| 04 | Catch the people who close the paywall | +5–12% CR to purchase |
| 05 | Put the 4.8 stars where the decision happens | +3–8% CR to purchase |

Every price, rating and feature comes from iHeart's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for iHeart. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
